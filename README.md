# omics Research workspace
a reproducible RNA-SEQ analysis workspace for simple and reliable downstream analysis.
This project will combine python, streamlit, R,DESeq2,SQLite,automated testing.
## project goals 
Build a clear workflow for researchers who do not want to edit analysis scripts mamually.
Validate count matrics,sample metadata, and experimental designs before analysis.
Connect a python application with statistical analysis performed in R
## planned workflow
1. Upload a count matrix and sample metadata.
2. Validate file structure and experimental design.
3. Run differential expression analysis with DESeq2.
4. Generate quality-control and differential-expression visualizations.
5. Perform GO and KEGG enrichment analysis.
6. Save reproducible reports and analysis history.
